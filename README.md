# CTRL & Create — Static Site

This folder is ready for GitHub Pages.

## Quick start (GitHub Pages)
1. Create a new public repo on GitHub named `ctrl-create` (any name works).
2. Upload the contents of this folder (keep **index.html** at the root and **assets/** with `logo.png` inside).
3. Go to **Settings → Pages** and set:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` (or `master`) / root (`/`)
4. Save. Your site will be live at `https://YOUR_USERNAME.github.io/REPO_NAME`.

## Local preview (optional)
Just open **index.html** in your browser.

## Customize
- Edit **index.html** copy, pricing, and sections as needed.
- Colors are defined as CSS variables at the top of the file:
  - Navy: #050a30
  - Mist: #d0d7eb
  - Royal: #1800ad
  - Snow: #f4f6fc
